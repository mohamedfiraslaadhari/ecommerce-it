# E-commerce Informatique

Plateforme e-commerce fullstack de vente de produits informatiques : React + TypeScript, Node.js/Express, MongoDB Atlas, Stripe.

## Structure du projet

- `backend/` : API REST Express
- `frontend/` : application React (Vite + TypeScript)

## Installation

1. Installer toutes les dépendances : `npm run install:all`
2. Copier `backend/.env.example` vers `backend/.env` et `frontend/.env.example` vers `frontend/.env`, puis renseigner les variables
3. Lancer le projet : `npm run dev`

## Adresses en local

- Backend : http://localhost:5000
- Frontend : http://localhost:5173
